# Python Fundamentals

A set of short Python programs covering input handling, validation, functions, text processing and simulation.

| Program | What it does | Concepts |
|---|---|---|
| `lightyears_converter.py` | Converts light years to kilometres, repeating until the user stops | Loops, input validation, exceptions |
| `ac_uk_domain_checker.py` | Checks whether a domain is a UK academic (`.ac.uk`) domain | Functions, type hints, string methods |
| `digit_sum.py` | Adds up the digits a user enters | Validation, iteration |
| `bmi_calculator.py` | Calculates BMI and reports the category | Unit conversion, conditionals |
| `text_analysis.py` | Counts words, sentences and how often a word appears in a text file | Regular expressions, file handling |
| `door_game_simulation.py` | Simulates a three-door game 100,000 times to estimate the chance of winning | Random numbers, simulation |

## Run a program

```bash
python bmi_calculator.py
```
